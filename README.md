## 🚀 Proyectos destacados

### 📊 Sistema de depreciación de activos

Proyecto en desarrollo para administrar activos y calcular su depreciación mensual mediante el método de línea recta.

**Características implementadas en el backend:**

- Creación, consulta, actualización y eliminación de activos.
- Asociación de activos con categorías.
- Cálculo de depreciación mensual, depreciación acumulada y valor en libros.
- Ajuste del último período para compensar el redondeo.
- Registro e inicio de sesión con hash de contraseñas y emisión de tokens JWT.
- Servicios separados para activos, depreciación e identidad.

**Tecnologías:** C# · ASP.NET Core · Entity Framework Core · SQL Server.

**Estado:** backend en desarrollo y base de frontend con React y Vite, pendiente de integración funcional.
